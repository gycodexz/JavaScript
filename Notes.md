# What is JavaScript?

JavaScript (JS) is a scripting language used to make web pages more responsive.


# History of JavaScript (JS)

JavaScript was developed by Brendan Eich in 1995, in only 15 days, by the original name Mocha, while he was working at Netscape Communications Corporation. Mocha had a purpose of adding responsiveness to web pages. But people weren't learning this language, so he changed the name of Mocha to JavaScript, with reference to JAVA, one of the most prominent languages of that time, because he wanted people to learn JavaScript, in the name of JAVA, and that worked. JS is now one of the most widely used scripting languages nowadays, in almost all browsers.

All companies had their own browser support languages, but then the web industry fixed a single language to be used, known as JavaScript. It took the best qualities of all the languages persisting at that time.

JavaScript had many loopholes, since it was made in only 15 days. They were fixed after many years of JS being developed, by the web community called EcmaScript, and JS had its own new verion, which had the name "ES5". EcmaScript maintains JavaScript nowadays.

ES5 also had problems. Then in another version, namely ES6, most of the problems were fixed. For example, var is a component of the ES5 JS, and let and const are components of the ES6 JS.
